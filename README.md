Token Radar ranks every pre-token protocol worth watching by an implied value grounded in the market: the median market-cap-per-TVL of the tokened protocols in its own category, shrunk toward the market-wide median, adjusted by 7-day growth, age with no token, and chain breadth. It ranks 226 protocols — all 40 watchlist slugs plus 186 early finds below the $50M floor — each with a factor-by-factor breakdown and a concrete farm plan with costs and times. The dashboard is sortable and filterable, with a live-token view and a model sandbox that re-ranks the whole board.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
